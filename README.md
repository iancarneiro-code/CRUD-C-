# CRUD de Conta Corrente - C# e .NET

## 1. Sobre o projeto

Este projeto foi desenvolvido em C# utilizando a plataforma .NET, com o objetivo de demonstrar a criação de um CRUD simples em uma aplicação Console.

A aplicação permite cadastrar, consultar, listar, alterar e excluir contas correntes. Os dados são armazenados apenas em memória, utilizando uma `List<ContaCorrente>`, sem conexão com banco de dados.

### Funcionalidades

- Cadastrar conta;
- Listar contas;
- Consultar conta;
- Alterar conta;
- Excluir conta;
- Validação de conta duplicada.

---

## 2. C# e .NET

C# é uma linguagem de programação desenvolvida pela Microsoft, orientada a objetos e utilizada principalmente no ecossistema .NET.

O .NET é uma plataforma de desenvolvimento gratuita, de código aberto e multiplataforma, utilizada para criação de aplicações Console, Web, APIs, Desktop, Mobile, entre outras.

### Principais características

- Programação orientada a objetos;
- Multiplataforma;
- Gerenciamento automático de memória;
- Grande biblioteca padrão;
- Suporte a programação assíncrona;
- Integração com o NuGet;
- Grande quantidade de documentação e ferramentas.

---

## 3. Vantagens e desvantagens

### Vantagens

- Sintaxe organizada e relativamente fácil de aprender;
- Grande quantidade de documentação;
- Grande comunidade de desenvolvedores;
- Suporte a diversas plataformas;
- Ecossistema amplo;
- Ferramentas como Visual Studio e Visual Studio Code.

### Desvantagens

- Grande quantidade de recursos pode dificultar o aprendizado inicial;
- O ecossistema possui diversas tecnologias, o que pode gerar dúvidas sobre qual utilizar;
- É necessário acompanhar as versões e períodos de suporte do .NET.
